# Claude entry point

Read and follow `AGENTS.md` at the repository root. It is the shared rule source
for Claude and Codex, including safety and explicit commit/push authorization.

Before owner work, read `private/AGENT_HANDOFF.md` when available. After each
major step and before ending a turn, update that shared handoff and append
evidence/results to `private/AGENT_WORK_LOG.md`. Do not create a parallel status
history. Public phase status remains in `docs/PROJECT_STATUS.md` and `docs/PHASES.md`.
